# Flipbook

A frame-by-frame drawing/animation app for kids. No build step, no dependencies — just `index.html`, `style.css`, and `app.js`.

Draw a page, flip through frames with onion-skinning, play back the animation, and export it as a GIF. Works on iPad Safari and macOS; designed to be added to the iPad Home Screen.

Data is stored locally per-device in IndexedDB — there's no sync or backend.

Hosted on GitHub Pages via the workflow in `.github/workflows/pages.yml`.
